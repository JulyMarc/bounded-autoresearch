# Publication safety

Before publication:

- confirm authorship and license compatibility;
- inspect all files and history for secrets, private paths, identities, datasets, logs, and provider credentials;
- use only synthetic examples;
- run tests from a clean clone;
- verify package metadata and links;
- avoid autonomy, scientific-validity, novelty, or benchmark-superiority claims not established by evidence;
- obtain explicit approval before Git initialization, commit, push, repository creation, or visibility changes.
