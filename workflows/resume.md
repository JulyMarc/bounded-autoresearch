# Resume workflow

1. Run validation. Stop on ledger/state mismatch or invalid transition.
2. Read the concise resume summary, then `FINDINGS.md`, `EXPERIMENTS.md`, and the current plan.
3. Confirm remaining experiment and resource budgets.
4. Do not repeat completed or killed experiments without a recorded reason.
5. Continue from the verified champion, not the last attempted configuration.
6. If blocked, preserve the blocker and required approval rather than silently weakening constraints.
